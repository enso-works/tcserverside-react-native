+### Disabling / enabling
+
+```ts
+TCServerSide.disableServerSide(): void
+TCServerSide.enableServerSide(): void
+```
+
+Use `disableServerSide` when a user opts out of tracking outside of the Consent module's flow. It stops all internal systems (background handling, connectivity listeners, hit processing) and makes every subsequent call a no-op until you call `enableServerSide` — you don't need to guard your own calls.
+
+### Advertising ID
+
+```ts
+TCServerSide.addAdvertisingID(): void
+```
+
+For privacy reasons, the advertising identifier (IDFA on iOS, AAID on Android) is never read automatically. Call this only after confirming the user has accepted the relevant consent category (and, on iOS 14+, after the system ATT prompt). It adds the identifier and its associated tracking-enabled flag to the native `context.device` payload for use on subsequent events.
+
+### Waiting for the user-agent (iOS)
+
+```ts
+TCServerSide.waitForUserAgent(): void
+```
+
+iOS-only — no-op on Android, which reads the user-agent synchronously and doesn't need this. Apple removed the synchronous API for reading it, and on real devices the async fetch can occasionally take over a minute. Call this if a destination requires the user-agent; hits waiting to be sent get it appended once it becomes available.

+
+Carried over from the SDK's v4→v5 migration path — only relevant if you're migrating from `TC_UNIQUEID`:
